01

তিনটি পরিচয় আগে বুঝুন

Operator প্রথমে accounting rule নয়, ব্যবসার চরিত্রগুলো চিনবে।

A

Customer

যে PE office কাজ দিয়েছে। উদাহরণ: LGED-BSL।

B

Project

যে awarded tenderটি এখন বাস্তব কাজ।

C

Ref.

Standalone Balance Sheet movement-এর tender identity।

D

Item

Correct account-এ line পৌঁছানোর standard non-inventory item।

মনে রাখুন: Customer = office, Project = awarded tender, Ref. = standalone Balance Sheet identifier, Item = entry routing tool।

03

Entry দেওয়ার আগে 10-second decision

একটি প্রশ্ন করুন: এই lineটি site income/cost, tender-specific Balance Sheet, না company-wide overhead?

Project lane

Revenue · Materials · Labor · Subcontractor · Equipment

Manager.io Project dropdown থেকে actual site Project select করুন।

Ref. lane

Tender/Performance Margin · Advance Receipt · Retention Release · Loan Principal

Ref. = PE-TenderID

Blank lane

Time Loan Interest · General Bank Charge · Office Overhead

Project blank + Ref. blank

Locked exception: Sales Invoice line-এ Ref. নেই। Invoice Header-এর Customer + Project পুরো RA Bill-এর context বহন করে।
