Locked System Rules

ALWAYS TRUE

এই নিয়মগুলো প্রতিটি tool-এ সামঞ্জস্যপূর্ণভাবে প্রয়োগ করা হয়েছে।

NOA Day: Customer (if missing) + Project তৈরি হয় একই সময়ে; Customer Code = Project PE CODE exact match।
Tagging: Site P&L cost/income → Project। Standalone tender-specific Balance Sheet movement → Ref. = PE-TenderID। Company-wide/unsplittable → both blank।
Sales Invoice Policy: Sales Invoice-Line Ref. = NO। Invoice Header Customer + Project পুরো context বহন করে।
Time Loan Interest: Account 5700 সবসময় untagged — Project blank, Ref blank।
BG Face Value: BG-only হলে ledger-এ কোনো cash-margin entry হবে না; শুধু BG Register track করবে।
Print Theme: Approved production baseline = PROCUREMENT-LEDGER-V1.8.0-STATELESS.html। Enriched themes deploy করা যাবে না।
