Door 01

Before NOA — Bid Stage

NOA আসার আগে কোনো Project নেই। এই সময়ের entry গুলো company-wide bid cost হিসেবে record হবে।

Door 02

NOA Day — Customer + Project Setup

NOA পাওয়ার সঙ্গে সঙ্গে দুটি কাজ একসাথে করুন। এটি আলাদা দিনে করার কাজ নয়।

Step 1 — Customer

Customers ট্যাবে PE office আছে কি না দেখুন। না থাকলে Name, Code (LGED-BSL), Region দিন।

Step 2 — Project

Name format: [Location]-[ShortName]-[PE]-[TenderProposalID]। PE CODE = Customer Code-এর exact copy।

🔒 NOA Code Match Validator

✓ Exact Match — Project তৈরি করা নিরাপদ।

Door 04

RA Bill Builder

Gross work, retention, advance recovery আলাদা রাখুন — নিচে নিজের সংখ্যা দিয়ে দেখুন।

Door 05

Security, BG & Retention Release

Tender Security, Performance Security, BG Register, এবং DLP-এর পরে retention release।

BG Register Fields

BG Number, Type, Issuing Bank, Face Value, Issue Date, Expiry Date, PE Code, Tender ID, Status, File Reference — BG face value কখনো ledger-এ ওঠে না।

Reference

Operator Desk Card

দ্রুত reference — Do's & Don'ts.

✓ সঠিক কাজ

  • Customer check ও Project একই সময়ে তৈরি করুন
  • আলাদা office হলে আলাদা Customer খুলুন
  • Customer Code হুবহু Project PE CODE-এ কপি করুন
  • Standard item prefix দিয়ে search করুন
  • Mobilization Advance-কে 2100 Liability হিসেবে রাখুন
  • Approved stateless print theme ব্যবহার করুন

✗ ভুল কাজ

  • Customer Name-এ Tender ID লিখবেন না
  • NOA-এর আগে Dummy Project খুলবেন না
  • Sales Invoice লাইনে Ref. লিখবেন না
  • BG-only হলে fake cash-margin entry করবেন না
  • Retention release-কে নতুন Revenue বলবেন না
  • Time Loan interest tag করবেন না
  • Enriched theme live-এ inject করবেন না
Closing line: Setup থেকে closeout পর্যন্ত — clean Customer, clean Project, correct Ref., correct item, and safe print theme.
