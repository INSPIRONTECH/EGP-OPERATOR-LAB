PART 4 — Non-inventory Items: ব্যবহার করার নিয়ম

10. Item select করার আগে

[VERIFIED] Non-inventory Items_14-AUG-26.md-এ item-এর account number, item name, bilingual description এবং unit name দেওয়া আছে। Manager.io-তে item list থেকে matching item select করলে line description এবং account selection consistent থাকে।

Operator rule

  1. ঠিক ঘটনার জন্য ঠিক item select করুন — শুধু account number দেখে কাছাকাছি item নেবেন না।
  2. Item-এর Unit বদলাবেন না, যদি source quantity ওই unit-এ থাকে।
  3. Tender identity item description-এ লিখবেন না; Balance Sheet movement হলে Ref. field ব্যবহার করুন।
  4. Site cost item হলে Project select করুন।
  5. New item দরকার মনে হলে নিজে create করবেন না; duplicate আছে কি না verify করে authorized setup process অনুসরণ করুন।

11. Tender document and bid-stage items

Tender জেতার আগে Project নেই। তখন item select করবেন, কিন্তু Project blank রাখবেন।

Situation Use this item Account Unit Project Ref.
e-GP portal document/submission fee Tender Doc - Submission Fee 5800 Fee Blank PE code only
Bid preparation, printing, courier Tender Doc - Preparation Cost 5800 Cost Blank PE code only
Other bid-stage cost Tender Doc - Misc Bid Expense 5800 Cost Blank PE code only

Form:      Payment

12. Tender Security items

Cash margin block

Situation Use this item Account Unit Ref.
Cash margin blocked for tender security TS Margin Cash Block 1130 Instrument PE-TenderID
Partial cash margin against BG-backed security TS Margin BG Partial Block 1130 UnitName* PE-TenderID
Margin funded through a real Time Loan drawdown TS Margin Loan Block 1130 Instrument PE-TenderID

after source note: *The source export displays UnitName for TS Margin BG Partial Block. [STATED] Treat this as a catalog-data label to confirm in Manager.io before use; do not change it from the SOP.

BG-only tender security

Situation Use this item Account shown in item source Operator treatment
BG issued, no cash block TS Margin BG 1130 Do not create a cash-margin entry merely because a BG exists; record the BG in BG Register. Record only actual commission/cash block when applicable.

[VERIFIED] The item source includes TS Margin BG under 1130, but BG face value itself is not a ledger asset or expense. Therefore, operator must record only the actual cash movement, not the BG face value.

Release and bank fees

Situation Use this item Account Unit Project / Ref.
Tender Security refunded/released TS Margin Release 1130 Instrument Ref. = same tender
BG issue commission TS BG Commission - Direct 5710 Fee Pre-NOA: Project blank; apply approved reference convention
Bank processing charge TS Margin Bank Charge 5720 Fee Project blank; apply approved reference convention

13. Performance Security items

Situation Use this item Account Unit Project / Ref.
Cash margin blocked PS Margin Cash Block 1140 Instrument Ref. = PE-TenderID
Margin released after DLP PS Margin Release 1140 Instrument Ref. = same tender
Direct BG commission PS BG Commission - Direct 5710 Fee Project if clearly single-tender
Multi-year commission paid upfront PS BG Commission - Prepaid Initial 1300 Instrument Balance Sheet; follow approved reference method
Monthly prepaid commission amortization PS BG Commission - Monthly Amortization 5710 Month Project if clearly single-tender
Bank processing charge PS Margin Bank Charge 5720 Fee Project blank unless approved policy says otherwise

[STATED] Direct vs prepaid BG commission depends on the approved accounting policy and supporting document. Do not select the prepaid item simply because the amount is large; duration/policy must support it.

Time Loan

Situation Use this item Account Unit Project / Ref.
Real cash drawdown/repayment Time Loan Cash Movement 2300 Movement Ref. only if clearly tender-specific
Monthly bank statement adjustment Time Loan Monthly Adjustment 5700 Month Project blank, Ref. blank

[VERIFIED] The 14-AUG item catalog names the 5700 item Time Loan Monthly Adjustment; the item name does not change the locked rule that 5700 Time Loan interest/adjustment remains untagged unless a separate approved policy explicitly changes it.
