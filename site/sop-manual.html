PART 1 — শুরুতে গল্পটা বুঝে নিন

একটা tender শুরুতে শুধু সম্ভাবনা। তারপর fee হয়, security হয়, NOA আসে, কাজ শুরু হয়, RA Bill হয়, টাকা আসে, কিছু টাকা আটকে থাকে। একদিন সেই আটকে থাকা টাকাও ফেরত আসে।

[STATED] Manager.io-তে এই গল্পটি পরিষ্কার রাখার জন্য তিনটি জিনিস আগে বুঝতে হবে:

  1. Customer — যে সরকারি PE office কাজটি দিয়েছে
  2. Project — যে tenderটি awarded হয়েছে
  3. Ref. — একটি tender-specific Balance Sheet movement-এর ছোট পরিচয়

Customer office-কে চেনে। Project tender-কে চেনে। Ref. সেই tender-এর margin, retention, advance বা loan movement-কে চেনে।

1. PE কে?

[STATED] PE = Procuring Entity = Procurement Authority। সহজ কথা: যে সরকারি office tender দেয়, কাজ দেখে, bill certify করে এবং টাকা দেয়।

LGED, PWD, EED, RHD, BWDB—এগুলো agency-এর নাম। একই agency-এর আবার ভিন্ন city, district বা division office থাকতে পারে। LGED Barishal এবং LGED Patuakhali একই agency, কিন্তু একই office নয়।

[STATED] Manager.io-তে একটি PE office/branch = একটি Customer।

Customer field কী লিখবেন Example
Name PE office-এর পরিষ্কার official name Local Government Engineering Department
Code Agency + office/branch code LGED-BSL, LGED-PTK
REGION/BRANCH/OFFICE Office বা zone BARISHAL, PATUAKHALI 
LGED Barishal office    → Customer Code: LGED-BSL
LGED Patuakhali office  → Customer Code: LGED-PTK

[INFERRED] একই Customer-এর নিচে দুই office রাখলে ভবিষ্যতে office-wise tender, receivable এবং history মিশে যাবে। তাই branch আলাদা হলে Customer-ও আলাদা।

ছোট নিয়ম

  • করবেন: Customer Name পরিষ্কার রাখবেন
  • করবেন: Customer Code-এ branch/office identity রাখবেন
  • করবেন না: Customer Name-এর মধ্যে Tender ID, Project name বা কাজের পুরো description ঢোকাবেন না

[STATED] Customer হলো office identity। Tender হলো Project identity।

2. Tender ID কী?

[STATED] Tender ID বা Tender Proposal ID হলো e-GP tender-এর স্থায়ী পরিচয় নম্বর। NOA, security paper, certificate এবং bill-এ এই নম্বরটি সাধারণত পাওয়া যায়।

Project name-এ Tender ID থাকবে। Tender-specific Balance Sheet movement-এ Ref.-ও সেই ID দিয়ে হবে:

Project: JHLKT-RoadRehab-LGED-1142857
Ref.:    LGED-1142857

[VERIFIED] Ref. format: PE-TenderID। শুধু 1142857 লিখবেন না; prefix থাকলে পরে চোখে দেখেই agency বোঝা যায়।

কোন number ব্যবহার করবেন?

Number ব্যবহার
Tender Proposal ID Project name ও Ref.-এর tender identity
Package No. Source document reference হিসেবে রাখুন; Project name-এ নয়
Contract No. Project name-এ নয়; slash/long legal format থাকলে reference field বা source file-এ রাখুন

3. NOA কী?

[STATED] NOA অর্থ Notification of Award। এটি আসার মানে tender আর সম্ভাবনা নয়—কাজটি আপনি পেয়েছেন।

NOA আসার আগে Project খুলবেন না। কারণ তখন কাজটি awarded হয়নি। NOA আসার পর Project খোলা হবে, এবং এখানেই একটি গুরুত্বপূর্ণ নিয়ম শুরু হয়।

4. RA Bill, Retention, Advance—একসঙ্গে বুঝুন

[STATED] RA Bill বা Running Account Bill হলো কাজ যতটুকু হয়েছে, তার progress bill। Manager.io-তে এটি Sales Invoice।

একটি RA Bill-এ সাধারণত তিনটি কথা থাকে:

  1. এই মাসে কত টাকার কাজ certified হলো
  2. PE কত টাকা Retention হিসেবে আটকে রাখল
  3. আগে দেওয়া Mobilization Advance থেকে PE কত টাকা recover করল

Retention

[VERIFIED] Retention হলো PE-এর কাছে থাকা আপনার পাওনা। এটি নতুন income নয়; Revenue RA Bill-এর সময়ই record হয়।

  • Account: 1150 Retention Receivable
  • DLP শেষে release পেলে: Bank-এ আসে

Mobilization Advance

[VERIFIED] Mobilization Advance হলো কাজ শুরুর আগে PE-এর দেওয়া টাকা। এটি income নয়; পরে RA Bill থেকে recover হবে।

  • Account: 2100 Mobilization Advance Received
  • Nature: liability

DLP

[STATED] DLP = Defect Liability Period। এই সময়ে কাজের defect থাকলে contractor-এর দায় থাকে। DLP এবং release condition সম্পূর্ণভাবে contract document দেখে confirm করবেন।

5. Security আর BG

Tender Security

[STATED] Bid করার সময় Tender Security লাগতে পারে। এটি cash, Pay Order, BG-only, অথবা BG-এর বিপরীতে cash margin—যে কোনোভাবে হতে পারে।

Performance Security

[STATED] Award-এর পরে Performance Security লাগতে পারে। এটি কাজের performance নিশ্চিত করার security। এর amount, method, expiry এবং release condition NOA/contract/BG document থেকে নেবেন—অনুমান করবেন না।

Bank Guarantee (BG)

[VERIFIED] BG face value নিজে income বা expense নয়। Cash margin এবং bank commission ledger-এ record হয়; BG number, issue date, expiry ও status আলাদা BG Register-এ রাখা হয়।

ঘটনা Manager.io treatment
Cash Tender Security 1130 Tender Security Margin + Ref.
Cash Performance Security 1140 Performance Security Margin + Ref.
BG-only, cash blocked নয় Ledger entry নয়; BG Register update
BG + cash margin Cash margin ledger-এ; BG details register-এ
BG bank commission 5710 Expense অথবা approved 1300 prepaid method

PART 2 — NOA আসার দিন

6. Award day rule: দুইটি record, একই সময়ে

[STATED] NOA পাওয়ার সঙ্গে সঙ্গে দুটি কাজ করবেন:

  1. Customer create/check — PE office আগে থেকে না থাকলে তৈরি করুন
  2. Project create — awarded tender-এর জন্য একটি নতুন Project

এটি আলাদা দিনে করার কাজ নয়। একই সময়ে করলে Code দেখে Code বসানো যায়। typo কম হয়। পরে কী লিখেছিলাম তা মনে করতে হয় না।

Step A — Customer আছে কি না দেখুন

Customers tab-এ search করুন। একই PE office-এর Customer আগে থেকে থাকলে আবার create করবেন না।

না থাকলে:

Field কী লিখবেন Example
Name PE office-এর নাম Local Government Engineering Department
Code PE CODE LGED-BSL
REGION/BRANCH/OFFICE Office/zone BARISHAL

[STATED] নতুন Customer বানানোর আগে একই Code বা একই office-এর duplicate আছে কি না দেখে নেবেন।

Step B — Project create করুন

প্রতি awarded tender-এর জন্য একটি Project।

Project field কী লিখবেন Example
Name Location-ShortName-PE-TenderID JHLKT-RoadRehab-LGED-1142857
Customer সেই PE office Customer LGED-BSL
PE CODE Customer Code-এর exactly same value LGED-BSL
Contract Value NOA/contract-এ থাকা awarded value source document থেকে
Retention Rate contract-এ থাকা rate source document থেকে

The one check that matters

Customer Code:      LGED-BSL
Project PE CODE:    LGED-BSL

[STATED] দুইটি value হুবহু এক হতে হবে—capital letter, hyphen, সবকিছু।

LGED-BSL   ✅
LGED BSL   ❌
lged-bsl   ❌
LGED       ❌

[INFERRED] এক PE office-এর বহু Project থাকতে পারে। Customer Code ও Project PE CODE এক রাখলে বহু বছর পরে office, tender এবং Project history filter করা সহজ থাকে।

Award-day checklist

[ ] NOA/source paper থেকে PE office, Tender ID, Contract Value, Retention Rate দেখেছি
[ ] Customers-এ same PE office এবং Code খুঁজেছি
[ ] না থাকলে Customer তৈরি করেছি
[ ] Project Name format মেনে Project করেছি
[ ] Customer Code = Project PE CODE, exact match করেছি
[ ] Ref. helper note লিখেছি: PE-TenderID
[ ] Source document link/file reference Project record-এ বা approved repository-তে রেখেছি

9. Project এবং Ref.—দুজনের কাজ আলাদা

Project

[VERIFIED] P&L account-এ Project ব্যবহার হবে। P&L মানে income বা expense—কোন site-এর লাভ/খরচ সেটা বোঝা দরকার।

RA Bill revenue         → Project
Materials               → Project
Site labor              → Project
Subcontractor cost      → Project
Equipment allocation    → Project
Liquidated damages      → Project, when directly project-related

Ref.

[VERIFIED] Tender-specific Balance Sheet line-এ Project selector available নাও থাকতে পারে। তখন Ref. দিয়ে tender identity রাখা হয়।

Tender Security margin        → Ref.
Performance Security margin   → Ref.
Retention release             → Ref.
Mobilization Advance receipt  → Ref.
Time Loan principal movement  → Ref., only if clearly tender-specific

Time Loan interest

[VERIFIED] 5700 Interest on Time Loan: Project blank, Ref. blank। Bank facility interest সাধারণত lump sum হয়; safe tender-wise split না থাকলে tag দেবেন না।

Final Sales Invoice policy

[STATED] Sales Invoice line-এ Ref. ব্যবহার করবেন না।

  • Invoice header-এ Customer থাকবে
  • Invoice context-এ Project থাকবে
  • Revenue, retention এবং advance recovery একই RA Bill-এর অংশ হিসেবে দেখা যাবে
  • Standalone Balance Sheet Receipt/Payment/Journal Entry হলে Ref. ব্যবহার হবে

10. Item select করার আগে

  5. New item দরকার মনে হলে নিজে create করবেন না; duplicate আছে কি না verify করে authorized setup process অনুসরণ করুন।
